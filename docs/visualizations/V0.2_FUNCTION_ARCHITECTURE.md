## 一次提交的证据保护序列

```mermaid
sequenceDiagram
    participant U as Streamlit
    participant A as FastAPI
    participant S as SubmissionService
    participant R as Repository protocols
    participant L as Analyzer / Diagnoser / History
    participant P as Prompt + ProviderRouter
    participant V as FeedbackValidator

    U->>A: POST /api/v1/submissions
    A->>A: Pydantic 输入验证
    A->>S: EssaySubmission
    S->>R: 保存原始作文
    S->>L: 分析、诊断、读取历史
    L-->>S: 指标、diagnosis_id、history_evidence_id
    S->>P: 结构化 FeedbackContext
    P->>V: Pydantic 后的候选反馈
    V-->>P: 引文、诊断 ID、历史 ID、练习关联验证
    P-->>S: 合格 DeepSeek 或 LocalDemo 反馈
    S->>R: 保存反馈、练习、历史和调用审计
    S-->>A: 结构化结果
    A-->>U: HTTP JSON
```

## 备份核对点

- Streamlit 不导入数据库、Repository、Analyzer、Diagnoser、FeedbackService 或 DeepSeekProvider。
- FastAPI route 不执行 SQL；核心服务不导入 Streamlit、FastAPI 或 sqlite3。
- DeepSeek 失败不会绕过验证，只会走同一验证器的 LocalDemo 回退。
- 版本化迁移保留旧数据；当前 `PRAGMA user_version=2`。
- PostgreSQL 只是 Repository 扩展点，尚未实现。
- 所有节点当前仍在同一台 Windows 电脑运行；图中的未来客户端不表示已开发。

纯文本回退：`Streamlit → HTTP → FastAPI → SubmissionService → Repository protocols → SQLite`；Analyzer、Diagnoser、History、Prompt、Provider 和 Validator 由 SubmissionService 编排。
