# 升级路径

## 1. CALF 与更复杂语言指标

- 保留现有 `Analyzer` 契约，新建版本化实现，逐步接入可靠的分词、句法分析、词汇频率和准确性标注。
- 将复杂度、准确性、流利度作为彼此独立的分析维度，不从单个表层指标推断能力。
- 建立人工标注样本、单元测试、版本回归集和指标适用范围说明。

## 2. 更严格的教学诊断

- 将启发式阈值移出代码，形成可审计、版本化的规则配置。
- 由应用语言学研究与教师共同定义证据链、置信度和禁用推断。
- 使用真实但合规的数据进行效度、可靠性、公平性和教师可用性研究；研究完成前继续标记为工作假设。

## 3. 学习者模型

- 区分文本表现、任务条件、教师判断、学习目标和练习完成情况。
- 采用任务可比性评分，而非当前的三个字段精确匹配。
- 用时间序列和不确定性表示变化，设置最小观测量；不把描述性变化直接命名为能力提升。
- 加入学生/教师纠正反馈的机制，避免错误历史被持续放大。

## 4. LLM 与反馈治理

- 增加 Provider 注册表、重试/限流、成本上限、结构化日志和脱敏策略。
- 建立 prompt 版本评测集，检查事实依赖、证据对齐、教学可操作性和不当能力判断。
- 引入教师审核、批准、编辑和反馈追踪；保存“机器建议”与“教师最终反馈”的区别。

## 5. 微信小程序或其他客户端

- 将 `FeedbackPipeline` 后移到经过认证的 API 服务，Streamlit 仅保留为研究管理界面。
- 小程序通过 HTTPS 调用后端；密钥只存后端秘密管理系统，绝不放在客户端。
- 增加账户、访问控制、审计、数据删除、同意管理、速率限制和异步任务队列。
- 在商业或教学部署前完成安全、隐私、可访问性和机构伦理审查。
