# v0.8.2 SPEC — Research Data Infrastructure

Frozen on 2026-07-30. This release builds auditable, privacy-aware, version-traceable research data export and lightweight human review infrastructure. It does not add new measurement, scoring, CEFR, model training, or v0.9 work.

## Authorization boundary

Research export pipeline (JSONL/CSV/manifest), three privacy modes, PII scanning/review, append-only human review, dataset builder with filters/splitting, data quality reports, configuration, migration, API, UI, tests, docs, and one Git commit. No CALF/Diagnostic/DeepSeek changes.

## Deliverables (abbreviated)

- Export Schema v0.1 with JSONL/CSV/manifest support
- PII scanner (regex-based with review workflow)
- Human Review schema/repository (append-only, separate from system records)
- Export pipeline with privacy modes: internal_research, pseudonymized, minimal_anonymous
- Dataset Builder with filters, preview, and student-level split
- Data Quality Report
- Migration 11 + config-v0.8.2
- API endpoints under /api/v1/research/
- Research Data tab in Streamlit Research Audit
- Comprehensive i18n for all new text
- Cases A–N automated tests
- Live A–E verification
- Full documentation suite
