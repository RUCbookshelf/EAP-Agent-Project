## 3. Compatibility re-export plan

- `app/ui/pages/student_pages.py` becomes a facade importing the six public renderers (`render_student_home`, `render_writing_page`, `render_feedback_page`, `render_feedback_content`, `render_revision_page`, `render_practice_page`, `render_learning_journey_page`) and every helper currently imported by tests (`_home_action_contract`, `_writing_saved_for_learner`, `_feedback_category_label`, `_practice_instruction`, `_practice_constraint_label`, `_practice_status_label`, `_revision_saved_for_source`, `_revision_observation_text`, `_revision_status_label`, `_journey_description_params`, `_journey_evidence_label`, `_journey_source_label`, `_journey_action_contract`) with explicit `__all__`.
- `app/ui/pages/research_pages.py` becomes a facade re-exporting the six Research renderers with explicit `__all__`.
- Facades contain no renderer, state, API-call, or business-display logic.
- Existing imports continue to work: `from app.ui.pages.student_pages import render_home_page`-style imports (and the private-helper imports used by `tests/test_student_experience_v094b.py`).
- No wildcard imports; no import cycles (features import only `app.ui.*` shared modules and `app.ui.contracts`; facades import features; `pages/__init__` imports facades; `streamlit_app.py` imports facades).

## 5. UI boundary-restoration plan

**Practice** (`app/ui/contracts/practice.py`): a frozen, presentation-safe exercise-instruction contract replaces the `app.practice.schemas.default_exercise_specifications` import. It contains only the exact learner-facing bilingual instruction strings (en/zh_CN) for the three frozen exercise types, with the identical lookup/fallback behavior (`learner_instructions.get(lang, ...get("en", exercise.instructions))`). No evaluation, target-selection, or domain-validation logic is copied. `_practice_instruction` keeps its name/behavior and delegates to the contract.

**Research Data** (`app/ui/contracts/research.py`): a UI-local helper `build_export_job_payload(privacy_mode, formats)` produces the plain dictionary with the exact shape previously produced by `ExportJob(filter_spec=ExportFilter(), privacy_mode=PrivacyMode(p), formats=[ExportFormat(f)...]).model_dump(mode="json")` (same keys, same enum string values, same defaults incl. `filter_spec` nested defaults, same `created_at` UTC ISO format). The page passes this dict to `api_client.research_export_preview/run`; `api_client.py` is unchanged (it already accepts dictionaries). Backend schemas and endpoints are untouched.

**Static guard** (`tests/test_v095c_ui_boundaries.py`): AST-based test asserting no production module under `app/ui` imports `app.practice.schemas`, `app.research.schemas`, `app.services.*`, `app.database.*`, or `app.repositories.*`; explicit allow-list for approved frontend dependencies (`app.config`, `app.errors` — the shared error taxonomy already consumed by `api_client.py`, `app.ui.*`).

4.
