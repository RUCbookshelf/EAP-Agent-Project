# V0.9.6-C2 SPEC - Sidebar Collapse Control Repair

**Status:** C2 implementation and focused verification complete (owner gate 2
pending). Baseline `41ad11f` (accepted C1 follow-up).

## Root cause (rendered-DOM proven, not assumed)

The native Streamlit sidebar collapse/expand control exists
(`[data-testid="stSidebarCollapseButton"]` / `stExpandSidebarButton`) and its
icon span contains the Material Symbols ligature text
(`keyboard_double_arrow_left` / `_right`). Computed styles showed the icon
span's `font-family` was the application's pixel body font stack
(`-apple-system, ...`) with `font-feature-settings: normal`, so the ligature
rendered as literal text instead of the arrow glyph. The pixel-art CSS rule
`div[data-testid="stSidebar"] * { font-family: var(--px-font-body)
!important; }` applied the pixel font to every sidebar element, breaking the
inheritance of Streamlit's own Material Symbols Rounded icon font (loaded by
the Streamlit distribution via @font-face; the icon span's own class rule sets
no font-family). The same over-broad rule also overrode the icon font in the
collapsed-state expand control.

## Fix (smallest source-proven change, `app/ui/pixel_art.py`)

1. Narrowed the sidebar text rule to button content:
   `div[data-testid="stSidebar"] *:not(button *)` plus
   `div[data-testid="stSidebar"] button` (sidebar labels/radios/captions keep
   the pixel body font; native button content keeps its own fonts).
2. Restored the icon font on the documented control testid:
   `div[data-testid="stSidebarCollapseButton"] span { font-family: "Material
   Symbols Rounded" !important; font-feature-settings: "liga" !important; }`.

No font-size:0, no transparency, no pseudo-elements, no fake arrows, no
position hacks, no sidebar replacement, no broad !important, no removal of the
native control or its accessible attributes.

## Browser/DOM evidence (fresh isolated database, real app)

- Before: literal `keyboard_double_arrow_left` text with the pixel font stack
  (`c2_sidebar_before.json`); control present but the glyph invisible.
- After (`c2_sidebar_after.json` + screenshots): icon font
  `"Material Symbols Rounded"`, `liga` active, literal-text rendering absent;
  exactly one control; mouse collapse (300 -> 0) and expand (0 -> 300);
  keyboard collapse/expand via focus + Enter (with Streamlit's hover-reveal);
  collapsed state shows the correct right-arrow expand control
  (`stExpandSidebarButton`); Home/Writing/Feedback/Revision/Practice all
  consistent; desktop 1280x900 and narrow 390x844 both toggle correctly.
