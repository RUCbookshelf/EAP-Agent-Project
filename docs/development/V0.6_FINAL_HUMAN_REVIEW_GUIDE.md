# Final human review gate after v0.6

## Page entry and interpretation

Open Essay submission, Student progress, Revision comparison and Local administration. Review at least one spaCy NLP
case, one fallback case, one version-segmented trend, one excluded draft, one light revision and one major rewrite.
Cross-check every displayed ID/version/limitation against API JSON and stored records.

## Research decisions still required

Review all active prototype parameters in `config-v0.6.1`, especially MATTR/repetition windows, long-sentence,
comparability, persistence/reduction, direction and variability thresholds, alignment similarity and uptake rules.
Mark thresholds lacking literature or empirical support as open researcher decisions; do not infer validation from
passing software tests. Review known parser/alignment misclassifications and exercise-source labels.

## Operations

Create, validate and activate a harmless draft, inspect the diff/audit, then rollback and verify a new AnalysisRun uses
the restored version while old runs remain. Preview each reanalysis scope. Confirm the default does not call an LLM and
the explicit path shows a cost warning and requires confirmation.

## Extension and stop gate

Review how to add an Analyzer, Metric and Algorithm through registries and where future CALF families attach. Before
v0.7, explicitly decide evidence sources, construct definitions, verification policy, threshold calibration, human
annotation and validation design. v0.7, full CALF, cloud deployment and WeChat work remain not started until authorized.
