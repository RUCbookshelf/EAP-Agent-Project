# v0.9 SPEC — Feedback–Practice–Transfer Foundation

Frozen on 2026-07-30. This version establishes an auditable formative-learning loop: validated diagnosis → selected revision priority → targeted practice → student attempt → practice evidence → within-task revision response → later independent-task evidence.

## Authorization boundary

Practice Targets, Exercise Specifications, Exercise Instances, Student Attempts, Practice Evaluation, Feedback Engagement Traces, Within-task Revision Responses, Transfer Evidence Candidates, Practice-aware Learner State, API, UI, locales, research export integration, migration 12, config-v0.9.0, tests, docs, and one Git commit. No scoring, CEFR, proficiency, mastery, causal claims, or v1.0.

## Conceptual boundaries

- Feedback delivery ≠ engagement
- Practice availability ≠ engagement
- Practice attempt ≠ correct application
- Practice-performance evidence = task-specific
- Within-task revision response = candidate, not causation
- Later-task transfer evidence = candidate, not learning proof

1. Versioned Practice Target from selected current priorities only

5. Conservative Practice Evaluation (rule-based, no mastery)
6. Feedback Engagement Trace
7. Within-task Revision Response Candidates
