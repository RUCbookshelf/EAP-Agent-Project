## 1. Stage objective

Establish a tested, centralized Hybrid Pixel System foundation that later
Student and Research page redesign stages (v0.9.4-B, v0.9.4-C) can consume
without creating a second design system or duplicating CSS.

Deliverables:

1. one canonical design-token contract;
2. one centralized token implementation;
3. Streamlit theme configuration aligned with the token contract;
4. readable body typography and constrained monospace usage;
5. an AA-compliant primary action color (measured);
6. shared geometry, spacing, focus, status, density, and responsive tokens;
7. a minimal accessible icon primitive / icon policy;
8. hardened shared component primitives;
9. UTF-8-safe localization fixes for the two known hardcoded strings;
10. tests proving the foundation;
11. real browser verification across all twelve pages;
12. no page-level redesign;
13. no backend, database, API, journey, or research-semantic change.

## 3. Architecture decision — canonical token source

**Decision:** extend `app/ui/pixel_art.py` as the single canonical token
source. It already owns this responsibility (colors/fonts/spacing/geometry
CSS), is imported only by the app shell, and has no valid responsibility
boundary conflict. No new token module is created.

- `DESIGN_TOKENS` (Python dict) becomes the one canonical token contract;
  `PIXEL_CSS` and `PIXEL_COMPONENT_CSS` are generated from it.
- No second Python token map; no Student/Research token files.
- `.streamlit/config.toml` repeats only the Streamlit-required theme keys
  (primaryColor, backgroundColor, secondaryBackgroundColor, textColor, font
  category). This intentional duplication is documented and covered by a
  theme/token parity test.

## 5. Selector strategy

- Global Streamlit styling uses only stable `data-testid` selectors and the
  documented stable `.st*` class selectors listed in section 2.5.
- New primitives carry stable `data-testid` attributes.
- No generated hashed Streamlit classes are used or introduced.
- Every global selector is documented in this SPEC.

## 6. Component scope (Phase 4)

Primitives added/updated in `app/ui/components.py` (backward-compatible):

- `field_error(message, lang)` — localized inline field-validation notice
  (`[data-testid="px-field-error"]`) with icon.
- `loading_box(text, lang)` — localized loading state
  (`[data-testid="px-loading"]`), no spinner animation.
- `data_table(rows, columns, lang, density="research")` — compact table
  wrapper using the existing `table_container` (`[data-testid="px-table-wrap"]`).
- `icon(name, size=16, label=None)` — local inline-SVG pixel icon primitive
  (`[data-testid="px-icon"]`); `aria-hidden` when decorative, `role="img"`
  + `aria-label` when it carries meaning.
- Notices/empty state/status badge: add stable testids and icons without
  changing call-site signatures.
- `validate_writing_form(...)` — pure validation helper used by the Writing
  page (Student ID, prompt, essay text, revision selection).

Deferred (documented, not implemented): progress indicator, filter controls,
modal/dialog, destructive confirmation, side-by-side diff, role-scoped
Student/Research page variants, content-width application, sidebar grouping,
raw-JSON table replacement across Research pages.

## 12. Rollback strategy

- The implementation is UI-only: no migration, no data writes, no backend
  behavior. Reverting the single implementation commit
  (`git revert`) restores the verified v0.9.3 baseline exactly.
- `.streamlit/config.toml` can be removed without runtime impact (Streamlit
  falls back to defaults, as before).
- Locale additions are additive keys; removal restores 368-key parity.

## 13. Implementation risks

| Risk | Mitigation |
|---|---|
| Global font change breaks pixel identity | mono retained for headings/data/brand; role tokens constrain usage |
| Global selectors affect unintended controls | every global selector documented; Phase 3 smoke + Phase 7 48-render matrix |
| Touch-target sizing causes mobile layout shift | token-driven min-height only for app-owned controls; overflow checks |
| Locale parity drift | parity test + UTF-8 scans |
| Existing tests assert old styles | legacy harnesses re-run; documented intentional changes (focus color unchanged; body font/action red changed) |
| Remote font/icon dependency | static audit forbids `@import`, `url(`, remote fonts/icons |
