# v0.8.2 Human Review Guide

## Purpose

This guide helps researchers verify the v0.8.2 research data infrastructure.

## Verification Steps

### 1. Export Pipeline
- Navigate to Research Data tab in Streamlit
- Select each privacy mode (internal_research, pseudonymized, minimal_anonymous)
- Run export preview and verify record counts
- Run actual export and verify file generation
- Check manifest.json includes git_commit, migration_version, config_version

### 2. PII Scanning
- Submit a test essay containing an email address
- Check PII candidates appear in the scan
- Review and confirm PII candidates
- Verify redacted text in subsequent exports

### 3. Human Review
- Create a human review for a diagnosis target
- Verify the review appears in the review list
- Check that system records are not modified

### 4. Data Quality
- Run the data quality report
- Verify submission counts, version coverage, and timing quality sections

### 5. Dataset Splitting
- Create a dataset split at the API level
- Verify student-level assignments (no student in multiple splits)
- Verify reproducibility with the same seed

### 6. Privacy Verification
- Verify PII candidates are not leaked into export text without review
- Verify pseudonymized mode produces stable pseudonyms
- Verify minimal_anonymous mode removes student_id

## Pre-v0.9 Checklist
- [ ] Export pipeline produces valid JSONL/CSV
- [ ] All three privacy modes function as documented
- [ ] PII scanning catches common patterns
- [ ] Human reviews are append-only
- [ ] Data quality report reflects actual database state
- [ ] Dataset splits are student-level and reproducible
