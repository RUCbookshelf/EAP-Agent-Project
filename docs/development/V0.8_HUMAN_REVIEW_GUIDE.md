# v0.8 Human Review Guide

Reviewers should inspect candidate offsets against the source sentence, record accept/reject, corrected offsets, annotator ID, timestamp, guideline version, and adjudication status. Candidate clause/T-unit labels must never be treated as validated by default.

For error imports, confirm exact span matching, category, proposed correction, source, status, and guideline. Only confirmed human/imported-corpus annotations become eligible evidence; eligibility alone does not calculate an Accuracy metric.

For interpretation, check task conditions, Analyzer/metric/unit versions, input sufficiency, timing source/quality, and limitations. Do not infer writing quality, proficiency, ability, CEFR, improvement, or a CALF total from any displayed value.
