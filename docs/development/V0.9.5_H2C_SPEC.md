## 6. Selected canonical name

`AnalysisRunReader` (no leading underscore).

**Rationale:** the contract is intentionally imported by more than one
infrastructure module, so the shared name must not use the module-private
leading-underscore convention (authorization section 4). The name preserves
the exact capability wording (`AnalysisRunReader`) while dropping only the
privacy marker.

## 7. Selected canonical module

`app/infrastructure/sqlite/repositories/contracts.py` (new).

**Rationale:** no existing narrowly scoped shared infrastructure contract
module exists in the SQLite repository package (the package `__init__.py`
re-exports only the nine concrete repository classes; `_SubmissionBundleReader`
and `_DiagnosticCalibrationReader` remain consumer-module-local). The
authorization explicitly permits
`app/infrastructure/sqlite/repositories/contracts.py` as the new location when
no suitable shared module exists. The module remains inside the
infrastructure/SQLite repository boundary and independent of concrete
repository implementations.

## 8. Import-direction proof
