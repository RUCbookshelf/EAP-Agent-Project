# v0.9.1 SPEC — UI Completion & Usability Refinement

Frozen on 2026-07-31. This version transforms the current technical prototype into a coherent, usable, and visually polished interface for students and researchers. It is a UI and integration version only.

## Authorization boundary

Role-based navigation (Student View / Research View), progressive disclosure, responsive layout, i18n completion, visual design system, accessibility improvements, temporary-file cleanup, test suite expansion, Playwright verification, documentation updates, and one Git commit.

No new backend logic, CALF calculations, diagnostic rules, linguistic metrics, practice-domain behavior, scoring, proficiency claims, scoring systems, corpus import, or machine learning.

## Information architecture

### Student View
- Home — task summary, latest status, next action
- Writing — submission form with clear field grouping
- Feedback — strengths, max 2 revision priorities, evidence, next step
- Revision — source draft, feedback review, revise, diff, observations
- Practice — target, exercise, attempt, evaluation
- Learning Journey — chronological observable events timeline

### Research View
- Overview — aggregate counts and data-quality warnings
- Evidence — submission, analysis, diagnosis, priority, evidence audit
- CALF Measures — grouped metric cards with status/confidence/limitations
- Learning Process — complete evidence chain inspection
- Research Data — export, privacy, filters, PII, human review, splits, quality
- System Audit — diagnostic audit, learner model audit, reanalysis, admin

## Visual design system

- Consistent page headers with explanatory subtitles
- Reusable components: status badge, metric card, evidence quote, limitation notice, empty state, timeline event, audit record
- Grouped cards, readable spacing, clear primary/secondary actions
- Accessible contrast, readable typography, responsive layouts
- Streamlit-compatible CSS only; no large frontend framework

## Responsive design targets

- Desktop width (1280+)
- Tablet width (768+)
- Mobile viewport (390 x 844)
