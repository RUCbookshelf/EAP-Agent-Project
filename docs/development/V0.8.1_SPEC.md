# v0.8.1 SPEC — CALF Dashboard & Multilingual UI Refinement

Frozen on 2026-07-30. This release does not add new measurement capability. It refactors the UI information architecture, CALF metric display, role-based views, and multilingual support without modifying CALF calculation logic, the Diagnostic Gate, the Learner Model, DeepSeek, or the core database design.

## Authorization boundary

UI/CALF presentation, role isolation, locale, responsive, config, test, verification, documentation, and a single Git commit. No new measures, no scoring, no CEFR, no v0.9.

## What stays frozen

- CALF computation, Metric Registry core, Measurement Specification
- Diagnostic Gate, Learner Model 2.0
- DeepSeek feedback logic, prompt templates
- Core database tables and append-only contracts
- All existing metric/diagnosis/learner/fixture tests

## Deliverables

### Locale files

- `locales/en.json` — all user-facing English text
- `locales/zh_CN.json` — matching Simplified Chinese
- All status labels, tab names, buttons, warnings, empty states, and metric explanations must come from locale; no hardcoded English

### Role-based views

- **Student View**: Feedback, My Revision, My Progress tabs; no metric IDs, no measurement status, no automation level, no research versions; no ability/score/CEFR/ranking language
- **Research Audit View**: Evidence, CALF Measures, Research Audit tabs; full metadata including construct, metric, formula, measurement status, confidence, analysis unit, version, and limitations
- Sidebar page selector remains for standalone pages (Student Progress, Revision Comparison, Learner Model Audit, Diagnostic Audit, Local Administration)
- A language picker in sidebar

### CALF classification

- Lexical Complexity (Diversity, Density, Sophistication)
- Syntactic Complexity (all candidates)
- Accuracy (unavailable unless annotations exist)
- Product Fluency (output rate)

### Metric card UI

Each metric rendered as a unified card with:
- Name, category, value, measurement status label, confidence, limitations
- Status labels: Research metric, Descriptive proxy, Automatic candidate, Unavailable
- No green/red color coding; neutral/info/warning palette only
- Expandable details sections

- New fields: `default_language`, `student_show_calf_details`, `research_show_measurement_metadata`, `ui_show_language_picker`
