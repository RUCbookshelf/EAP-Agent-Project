# v0.6.1 Human Review Guide

This review checks diagnostic calibration, not student proficiency. Use pseudonymous or synthetic data only.

## 1. Open the audit

Start with `run.bat`, open Streamlit at `http://127.0.0.1:8501`, choose **Diagnostic audit** in the sidebar, and enter a submission ID. The page reads the FastAPI endpoint; it does not calculate diagnoses locally.

## 2. Read signal states

- **Raw signals**: every local heuristic candidate.
- **Monitored signals**: retained for research but not sent as feedback.
- **Eligible diagnoses**: passed the gate before ranking.
- **Selected priorities**: relevant evidence and score passed; only these may reach feedback.
- **Suppressed diagnoses**: inspect `exclusion_reasons`, `selection_reason`, evidence status, gate version, and score components.

## 3. Recalculate lexical metrics

For TTR, verify `type_count_used / token_count_used == value`. Confirm `token_definition=alphabetic_spacy_tokens`, lowercase-surface normalization, punctuation/numbers excluded, and `lemma_used=false`. For MATTR, additionally verify window size, effective-window count, and minimum text length. Lemma frequencies are separately labelled and must not be substituted silently.

## 4. Check evidence and exercises

Confirm each quotation is both verbatim and relevant to the category. A lexical quote must contain the diagnosed term; a connective quote/location must show the expression or exact relation/boundary. Selected high/medium/low diagnoses may receive at most 3/2/1 exercises; monitored and suppressed signals receive none. Synthetic material must be labelled `synthetic_practice_sentence`, never “your sentence.”

## 5. Fixed First Draft case

Use `tests/fixtures/diagnostic_calibration/first_draft.json`: S01, first draft, “Is history a lie?”, argumentative, timed 30 or 45 minutes, no tools. Confirm `history` and `lie` are prompt keywords; `bias` occurs in sentences 2, 6, and 11, has no local cluster, and is not selected. Confirm Furthermore, However, and Ultimately are detected; word count remains descriptive; lexical metrics can be recomputed; only selected priorities get exercises.

## 6. Linked Revised Draft case

Use `tests/fixtures/diagnostic_calibration/revised_draft.json` and link it to the fixed first draft. Confirm the Revision Snapshot remains available, suppressed first-draft signals are not labelled solved, monitored evidence stays research-only, diagnosis versions remain separate, and longitudinal trends are not merged with within-task revision change.

## 7. DeepSeek and LocalDemo

With the ignored local `.env` configured, run `$env:RUN_LIVE_LLM_TESTS='1'; .\.venv\Scripts\python.exe -m scripts.verify_live_deepseek_v061`. Confirm provider `deepseek`, StructuredFeedback validation `passed`, and `fallback=false`. Then set `LLM_PROVIDER=local` temporarily and submit the same fixture: LocalDemo must honor the identical selected set and may return zero priorities.

## 8. Current calibration parameters

Active configuration: `config-v0.6.2` (the requested `config-v0.6.1` already existed and remains preserved). Defaults: maximum priorities 2; score threshold 0.52; repetition count 4; density 0.025; local cluster required for low count; prompt penalty 1.0; necessary-term penalty 0.7; specific connective location required; exercise maxima 3/2/1; monitored exercises disabled.

None of these thresholds has literature, classroom, educational-effectiveness, fairness, or measurement-validity calibration.

## 9. Create, activate, and roll back configuration

In **Researcher administration**, create an immutable draft with a change note, validate it, and activate only after validation passes. To return to v0.6 behavior, roll back the active `config-v0.6.2` to its parent `config-v0.6.1`. Both versions and all prior AnalysisRuns remain stored.

## 10. Before CALF development

Obtain explicit approval and decide, with literature and human-coded data, the target constructs, token/sentence/T-unit definitions, parser-error policy, minimum sample sizes, validity/reliability design, multilingual/learner-text robustness, version-bridging rules, and teacher override process. v0.7 and CALF remain `not_started`.
