**Status:** C1 implementation and focused verification complete (owner gate 1
pending). Baseline `40f5a04`.

## Defect

Student S02's Submission #28 produced a valid no-priority Diagnostic Gate
result, but the UI dead-ended: Feedback rendered the no-priority result with
a single "Continue writing" route and never cleared the stale
`submission_result` session key, so Writing re-rendered the same saved panel
with "Review Feedback" - a deterministic two-page loop. Additional defects:
"Suggested Next Step" rendered twice, and the backend's neutral passage
("no reliable automatic strength was inferred") was labelled "Strengths".

## Incident classification (read-only)

Submission #28: S02, final draft, linked revision of 26 (RG000005, seq 4),
analysis AR000027, feedback 27 `fallback_success` with `priority_feedback:
null`, no exercises, no practice targets, diagnosis with empty strengths.
Backend data is complete and correct; the dead end is session-state and
navigation only.

## Fix (UI-only; no backend change)

- Feedback no-priority branch: two explicit choices - **Revise This Draft**
  (enters the existing Writing revision mode with the current submission
  preserved as source; no priority fabricated) and **Finish This Feedback
  Cycle** (acknowledges the reviewed result in session state, clears the
  stale saved panel, returns to a fresh Writing state; never deletes,
  creates, or submits anything).
- "Suggested Next Step" rendered exactly once; the action block uses
  "Choose your next step".
- Strengths section: neutral "Passage From Your Writing" heading whenever
  the diagnosis has no structured strength (no unsupported Strength label).
- Home: while the no-priority result is unresolved, shows "Latest
  submission #28 / No automatic priority selected / Review and choose" with
  the same two controls; after finish, returns to the normal contract.
- Writing: consumes the revision-source preset (correct source preserved),
  shows a one-shot cycle-finished notice, and renders a fresh form after
  finishing.
- Revision: explains absent automatic focus without fabricating one.
- Practice: explains that the target is absent because no priority was
  selected and routes to Writing.
- Locale: 12 new en/zh keys (parity 540/540).
