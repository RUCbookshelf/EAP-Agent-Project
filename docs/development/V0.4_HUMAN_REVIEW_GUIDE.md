# v0.4 human review guide

Open Streamlit at `http://127.0.0.1:8501`, API docs at `http://127.0.0.1:8000/docs`, and inspect health, one submission and its `/analyses` history.

Review these cases:

1. Prompt `Is history a lie?`; repeat `history` six times across separated sentences. Confirm prompt-keyword marking and low weight when no local cluster exists.
2. Repeat a non-prompt adverb such as `frequently` three times locally. Confirm located repetition and cautious diagnosis.
3. Use cause, contrast, exemplification and conclusion expressions. Confirm form, function, sentence, paragraph and offsets; confirm feedback never says all cohesion is absent.
4. Prefix an essay with `Here is a refined version...`, Markdown and a code fence. Confirm flags, unchanged raw text and no AI-use accusation.
5. Include one sentence above 30 parser tokens. Confirm a candidate and limitation, not an error or advanced-complexity claim.
6. Submit fewer than 50 lexical tokens. Confirm MATTR `insufficient_data` with window retained.
7. Set `SPACY_MODEL` to a missing package in a disposable environment. Confirm health and AnalysisRun expose BasicAnalyzer fallback/reason.
8. Compare BasicAnalyzer and SpacyAnalyzer runs for one essay. Confirm separate AnalysisRuns and version limitations; no old row is overwritten.

Known misclassifications include learner-language parse errors, ambiguous connective functions, missing implicit cohesion, improper-noun/topic-keyword decisions, duplicated boilerplate and title detection. All thresholds require literature review and empirical calibration.

Do not interpret any result as CEFR, CALF total, proficiency, verified development or a replacement for teacher judgment.
