# v0.4 SPEC — NLP Analyzer 2.0

Status: `completed`. Scope is bounded by the owner-supplied v0.4-v0.6 goal.

## Required outcome

Add an interface-driven, registered and versioned `SpacyAnalyzer` while preserving `BasicAnalyzer` as an explicit fallback. Persist append-only AnalysisRun, MetricResult, ResourceVersion and analysis-artifact evidence. Add input-quality flags, lemma/content-word/prompt-keyword repetition, MATTR and lexical-density prototypes, located/function-classified connectives, and cautious parser-derived syntactic candidates. Feed only structured evidence to the diagnosis and protected LLM path.

## Invariants

- Streamlit calls FastAPI only; routes do not run NLP; services depend on interfaces.
- Raw essays and earlier analyses are never overwritten or silently recomputed.
- spaCy/model absence records fallback state and reason; BasicAnalyzer keeps the system operational.
- `spaCy` and `en_core_web_sm` are pinned and installed/checked by `run.bat`; no large model is required.
- Metrics, resources, algorithms, parameters, duration, analyzer/model versions and limitations are traceable.
- Mixed analyzer/metric versions are separated or explicitly limited in longitudinal outputs.
- No CALF total, CEFR, grammar-error total, proficiency score or validated ability claim.
- DeepSeek remains optional and is only live-tested when `RUN_LIVE_LLM_TESTS=1`.
